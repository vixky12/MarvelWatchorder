# Multiverse Archive — MCU Watch Order

A mobile-friendly, static Marvel Cinematic Universe watch companion.

## Run it
Open `index.html` in a modern browser. No build tools, server, API key, or payment required.

## Put it online free (GitHub Pages)
1. Create a GitHub repository (Public).
2. Upload `index.html` from this folder to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish the URL. Open that URL on your phone and use your browser's **Add to Home screen** option.

## Features
- Release order and approximate in-universe timeline order
- Search, phase and watched-status filters
- Watched progress saved locally in the browser
- IMDb, Rotten Tomatoes search and detail links
- Poster thumbnails requested dynamically from Wikipedia page images, with designed fallback cards
- Major MCU series and special-presentation branch guide

## Notes
Fan-made, unofficial companion. Movie scope is MCU theatrical films plus the MCU-connected Sony Spider-Man entries listed through 2026. Series are presented as a companion branch, not interleaved episode-by-episode. Poster retrieval requires an internet connection and may vary by browser/network. IMDb and review links are search links to avoid brittle title IDs. The chronology is an approximate viewing sequence, not a substitute for Disney+'s continuously updated official timeline.
